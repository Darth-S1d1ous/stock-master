## 目标

## 变更原则

1. 新需求优先增加表、字段或索引，不复用已有字段承载不同语义。
2. 当前态与历史事实分离：当前态用于查询，历史表只追加。
3. 所有子资源外键尽可能包含 `user_id`，数据库与 Repository 双重保证所有权。
4. 迁移必须支持已有数据回填；无法安全降级时应显式拒绝，而不是静默丢失历史。
5. 数据源密钥只从环境变量读取，任何数据库字段和日志均不得保存密钥。
